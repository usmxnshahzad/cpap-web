# CPAP — Cerebral Palsy App (prototype)

Frontend-only **Next.js** (React + TypeScript) demo for **CP Care for Cerebral Palsy in Pakistan** (IHHN). Patient, doctor, booking, and video content is sample data. There is no backend.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:3000`).
